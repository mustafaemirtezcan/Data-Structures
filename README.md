# 🧑‍💻Data Structures

C++ assignments, each built around a different data structure. Every folder has the assignment description, sample input/output files and the source code.

- **Clear Vision:** Grayscale image processing: mean, Gaussian and unsharp filters, image arithmetic, and hiding messages inside images.
- **Asteroid Dash:** A grid-based space shooter that keeps falling objects and the leaderboard in linked lists.
- **Drone Alpha:** Plans a drone's route across provinces with hand-written stacks and queues, respecting priority and weather constraints.
- **H.U.Sland:** A game world stored in an AVL tree, with an array-based tree of players who climb the ranks by winning duels.
