# Data Structures

Assignments in C++. Each folder contains the assignment description, sample input/output files and the source code.

- **Clear Vision:** Image filtering and steganography on grayscale images.
- **Asteroid Dash:** Grid-based game built on linked lists.
- **Drone Alpha:** Route planning with stacks and queues.
- **H.U.Sland:** Game world stored in an AVL tree, with an array-based player ranking tree.
