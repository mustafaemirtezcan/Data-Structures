# 🧑‍💻Data Structures

C++ assignments, each built around a different data structure. Every folder has the assignment PDF, sample I/O and the source code.

- **A1 - Clear Vision:** grayscale image operations: mean, Gaussian and unsharp filters, image arithmetic, and hiding messages inside images.
- **A2 - Asteroid Dash:** a grid-based space shooter that keeps falling objects and the leaderboard in linked lists.
- **A3 - Drone Alpha:** plans a drone's route across provinces with a hand-written stack and queue, respecting priority and weather constraints.
- **A4 - H.U.Sland:** a game world stored in an AVL tree, plus an array-based tree of players that climb the ranks by winning duels.

Each project builds with the `Makefile` in its `src` folder.
